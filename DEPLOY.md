# Деплой на Render — пошаговая инструкция

Сайт задеплоен на [render.com](https://render.com) (бесплатный тариф). Два раздела:
инструкция для себя (сделать один раз) и готовый текст для заказчика.

---

## Часть 1. Как задеплоить (делается один раз)

### Что нужно заранее
- Аккаунт GitHub с этим репозиторием.
- Токен Apify (лежит локально в `.env`, строка `APIFY_TOKEN=...`).

### Шаги

1. **Регистрация**: зайди на [dashboard.render.com](https://dashboard.render.com) → **Sign up with GitHub** (карта не нужна).
2. **Новое приложение**: нажми **New +** → **Web Service**.
3. **Подключи репозиторий**: выбери свой `test-pifpaf` из списка (если его нет — нажми *Configure account* и дай Render доступ к репозиторию).
4. **Настройки сервиса** (при создании):
   - Name: `pifpaf-bloggers` (от него зависит адрес `pifpaf-bloggers.onrender.com`)
   - Language: **Node**
   - Branch: `main`
   - Build Command: `npm install`
   - Start Command: `npm start`
   - Instance Type: **Free**
5. **Переменные окружения** (раздел Environment): добавь три строки —

   | Key | Value |
   |---|---|
   | `APIFY_TOKEN` | твой токен из `.env` |
   | `APIFY_MOCK` | `0` |
   | `SESSION_SECRET` | любая длинная случайная строка |

   Случайную строку можно получить командой:
   ```bash
   node -e "console.log(require('crypto').randomBytes(32).toString('hex'))"
   ```
6. Нажми **Deploy Web Service** и подожди статуса **Live** (первая сборка ~3–5 минут).
7. Открой адрес вида `https://pifpaf-bloggers.onrender.com` — должна открыться лента с демо-данными (они сеются автоматически при пустой базе).

> Важно: именно переменная окружения `APIFY_MOCK=0` включает живой режим.
> Без неё (или без токена) сайт работает на мок-данных — это безопасный дефолт.

## Часть 2. Инструкция для заказчика (можно переслать как есть)

> Сайт доступен по ссылке: **https://<твой-адрес>.onrender.com**
>
> **Как посмотреть демо без регистрации:** на главной уже есть лента рилсов трёх демо-блоггеров. Можно войти за любого из них: `alina@demo.ru` / пароль `demo1234`.
>
> **Как протестировать на живом рилсе:**
> 1. Нажмите «Войти» → «Регистрация», заполните имя, e-mail, пароль и укажите свой Instagram-ник.
> 2. В кабинете нажмите **«Добавить рилс»** и вставьте ссылку на рилс, например:
>    `https://www.instagram.com/reel/Cxxxxxxx/`
>    Через несколько секунд появятся обложка, просмотры, лайки, комментарии и дата.
> 3. Кнопка **«Подтянуть профиль»** добавляет сразу последние рилсы по Instagram-нику.
> 4. Кнопка **«Обновить статистику»** освежает цифры по всем рилсам пользователя (сделана отдельно, чтобы экономить лимиты Apify).
>
> **Один нюанс:** сайт работает на бесплатном тарифе и «засыпает» после 15 минут без посетителей. Если страница грузится дольше минуты — просто обновите её ещё раз, сервис просыпается.

## Часть 3. Правила бесплатного тарифа Render

Полностью бесплатного лимита времени нет — есть ограничения:

| Параметр | Значение | Что это значит для нас |
|---|---|---|
| Цена | $0, карта не нужна | деплой ничего не стоит |
| Часы работы | 750 ч/мес на аккаунт | хватает на один сервис 24/7 |
| Сон | засыпает после 15 мин без запросов | первый запрос просыпается ~1 минуту |
| Диск | эфемерный | база обнуляется при каждом сне/редеплое |
| Мощности | 0.1 CPU / 512 MB | для демо достаточно |
| Трафик | ~100 ГБ/мес, сборки ~500 мин/мес | для теста с запасом |
| Домен | свой домен можно, HTTPS бесплатно | pifpafai-домен подключим позже без доплат |

**Главное следствие — эфемерный диск.** SQLite-файл (`data/pifpaf.db`) живёт только пока сервис не уснул или переdeployился. Поэтому:

- при старте сервер **автоматически сеет демо-данные**, если база пустая (см. `server/index.js`) — лента никогда не выглядит сломанной;
- **зарегистрированный заказчиком аккаунт и его рилсы пропадут**, когда сервис уснёт или после нового деплоя. Для короткой демонстрации это нормально;
- если нужно, чтобы данные жили весь день демонстрации: повесь бесплатный «пингер» ([cron-job.org](https://cron-job.org)) на адрес сайта раз в 10 минут — сервис не уснёт;
- для постоянного хранения данных нужен платный план (Starter, $7/мес — без сна + персистентный диск) либо перенос базы на внешний PostgreSQL.

**Apify (про токен):** бесплатный план даёт ограниченный кредит вычислений в месяц (~$5). Один вызов скрейпера стоит доли цента, так что тестов заказчика хватит с запасом. Расход виден в консоли Apify.
