# PifPaf Bloggers Dashboard 

Сайт для внутренних блоггеров PifPaf: лента рилсов с автоподтяжкой данных из Instagram (Apify), личные кабинеты с красивой аналитикой.

## Возможности
- **Лента рилсов** всех блоггеров — masonry-сетка с обложками, просмотрами, лайками, датами (стиль Pinterest / pifpafai.com)
- **Личные кабинеты** — регистрация/вход (bcrypt + JWT), каждый блоггер видит только свои рилсы
- **Автоподтяжка из Instagram** через Apify:
  - по ссылке на рилс (актор `social_developer/instagram-post-link-scraper`)
  - по ник-нейму профиля (актор `instagram-scraper/instagram-profile-reels-scraper`)
  - кнопка «Обновить статистику» — экономит бесплатные кредиты (снапшоты кэшируются в БД)
- **Дашборд-аналитика**: суммарные просмотры, прирост за 7 дней, топ-рилс, график просмотров по дням, история роста по каждому рилсу

## Стек
Node.js 22 · Express 4 · better-sqlite3 (SQL) · vanilla JS + HTML/CSS · canvas-графики без библиотек

## Запуск
```bash
npm install
npm start            # → http://localhost:3000
npm run seed         # демо-данные (по желанию; при пустой базе сеются автоматически)
```

Деплой на Amvera (российское облако, стартовый баланс 111 ₽ без карты): см. [DEPLOY.md](DEPLOY.md).

## Режимы данных
| Режим | Как включить | Что происходит |
|---|---|---|
| Мок (по умолчанию) | `APIFY_MOCK=1` | синтетические рилсы, Apify не вызывается |
| Живой | `APIFY_MOCK=0` + токен в `.env` | реальные данные из Instagram |

Проверка интеграции Apify:
```bash
APIFY_MOCK=0 npm run smoke
```
