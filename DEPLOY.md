# Деплой на Amvera — пошаговая инструкция

Сайт задеплоен на [amvera.ru](https://amvera.ru) — российском облаке (аналог Render/Koyeb, принимает российские карты). Два раздела:
инструкция для себя (сделать один раз) и готовый текст для заказчика.

---

## Часть 1. Как задеплоить (делается один раз)

### Что нужно заранее
- Аккаунт GitHub с этим репозиторием (или просто файлы проекта — можно загрузить вручную).
- Токен Apify (лежит локально в `.env`, строка `APIFY_TOKEN=...`).

### Шаги

1. **Регистрация**: зайди на [cloud.amvera.ru](https://cloud.amvera.ru) → «Регистрация» (почта + пароль,
   **карта не нужна**). Сразу при регистрации начисляется стартовый баланс **111 ₽**.
2. **Создай проект**: кнопка **«Создать проект»** → тип сервиса **«Приложение»** →
   название (например, `pifpaf-bloggers`) → тариф **«Пробный»** (0,1 CPU / 100 МБ RAM / 2 ГБ SSD).
3. **Загрузи код** — два варианта на выбор:
   - *Через GitHub*: во вкладке «Репозиторий» раскрой блок «Подключить GitHub», скопируй URL вебхука
     и секрет, добавь их в настройках репозитория на GitHub (**Settings → Webhooks → Add webhook**,
     Content-type: `application/json`, ветка `main`). После этого каждый `git push` в `main`
     автоматически пересобирает сайт.
   - *Вручную*: вкладка «Репозиторий» → папка `Code` → «Загрузить данные» → перетащи файлы проекта
     (без `node_modules` и без папки `data`).
4. **Конфигурация**: в репозитории уже лежит `amvera.yml` — окружение Node.js 22, команда запуска
   `npm start`, порт 3000, постоянное хранилище монтируется в `/data`. Ничего дополнительно указывать
   не нужно — при создании проекта на последнем шаге выбери окружение **Node.JS Server / npm** или
   просто нажми «Завершить» (файл конфигурации подтянется из кода).
5. **Переменные окружения** (раздел «Переменные и секреты» / «Environment») — добавь:

   | Key | Value |
   |---|---|
   | `DB_PATH` | `/data/pifpaf.db` — база будет жить в постоянном хранилище и переживёт редеплои |
   | `APIFY_TOKEN` | твой токен из `.env` |
   | `APIFY_MOCK` | `0` |
   | `SESSION_SECRET` | любая длинная случайная строка |

   Случайную строку можно получить командой:
   ```bash
   node -e "console.log(require('crypto').randomBytes(32).toString('hex'))"
   ```
6. Дождись статуса **«Приложение запущено»** (первая сборка ~2–4 минуты: npm install + сборка better-sqlite3).
7. Открой адрес вида `https://pifpaf-bloggers-<ник>.amvera.io` (ссылка видна в шапке проекта) —
   должна открыться лента с демо-данными (они сеются автоматически при пустой базе).

> Важно: именно переменная окружения `APIFY_MOCK=0` включает живой режим.
> Без неё (или без токена) сайт работает на мок-данных — это безопасный дефолт.

## Часть 2. Инструкция для заказчика (можно переслать как есть)

> Сайт доступен по ссылке: **https://<твой-адрес>.amvera.io**
>
> **Как посмотреть демо без регистрации:** на главной уже есть лента рилсов трёх демо-блоггеров. Можно войти за любого из них: `alina@demo.ru` / пароль `demo1234`.
>
> **Как протестировать на живом рилсе:**
> 1. Нажмите «Войти» → «Регистрация», заполните имя, e-mail, пароль и укажите свой Instagram-ник.
> 2. В кабинете нажмите **«Добавить рилс»** и вставьте ссылку на рилс, например:
>    `https://www.instagram.com/reel/Cxxxxxxx/`
>    Через несколько секунд появятся обложка, просмотры, лайки, комментарии и дата.
> 3. Кнопка **«Подтянуть профиль»** добавляет сразу последние рилсы по Instagram-нику.
> 4. Кнопка **«Обновить статистику»** освежает цифры по всем рилсам пользователя (сделана отдельно, чтобы экономить лимиты Apify).
>
> Сайт работает круглосуточно, без «засыпания».

## Часть 3. Деньги и правила тарифа

Тарификация поминутная (списание раз в час), только пока проект запущен. Остановил проект в кабинете — списания мгновенно прекращаются, остаток баланса сохраняется.

| Параметр | Пробный тариф | Что это значит для нас |
|---|---|---|
| Цена | 0,24 ₽/час = 170 ₽/30 дней | стартовых 111 ₽ хватает на ~19 суток непрерывной работы |
| Ресурсы | 0,1 CPU / 100 МБ RAM / 2 ГБ SSD | для демо достаточно (Express + SQLite лёгкие); если будет тесно — «Начальный» за 290 ₽/мес (500 МБ RAM) |
| Сон | нет, работает 24/7 | пингер не нужен |
| Карта | не нужна до момента пополнения | пополнить можно российской картой, когда понадобится |

**Хранилище.** У Amvera три папки: `Code` (код из git), артефакты сборки (пересоздаются) и **`Data` —
постоянное хранилище**, которое монтируется в контейнер по пути `/data` (задаётся в `amvera.yml`,
параметр `run.persistenceMount`). Поэтому мы задаём переменную `DB_PATH=/data/pifpaf.db`:
база SQLite переживает рестарты и передеплои — регистрация заказчика и его рилсы не пропадут.

Единственное исключение — загруженные аватарки (`public/uploads/`) остаются на эфемерном диске
артефактов: после редеплоя они сбрасываются, пользователи без аватарки увидят кружок с инициалами.
Это не ломает ничего; если захочется постоянства — можно аналогично перенести через `DB_PATH`-подобную
настройку или внешний S3.

**Если деньги на балансе кончились**: проект сам остановится (уйти в минус нельзя). Перед демонстрацией
зайди в кабинет и нажми «Запустить» — через минуту сайт снова живой.

**Apify (про токен):** бесплатный план даёт ограниченный кредит вычислений в месяц (~$5). Один вызов
скрейпера стоит доли цента, так что тестов заказчика хватит с запасом. Расход виден в консоли Apify.
